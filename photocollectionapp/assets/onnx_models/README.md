# Log end detection model
Should be named `log_ends.onnx` and placed in this folder.

Models are found on sharepoint:

```DIIF>Utveckling>Stockar>results>models>detectron...```
```DIIF>Utveckling>Stockar>results>models>yolo_model...```

The yolo model is only free for non-commercial use, so preferably we use the detectron model. The yolo model can be used for comparison and benchmarking.
